Cookies och mätning

Nödvändigt: vi sparar ditt cookieval i webbläsaren så att vi inte frågar igen.

Bara med ditt samtycke: Meta Pixel (Meta Platforms Ireland Ltd) och Googles tagg (Google Ireland Ltd). De används för att mäta hur våra annonser fungerar och för att kunna visa annonser för personer som besökt sidan. Inget av detta laddas innan du har tryckt på "Godkänn". Väljer du "Endast nödvändiga" laddas ingenting.

Du kan ändra ditt val när som helst via "Cookie-inställningar" längst ner på sidan.

Var uppgifterna finns och vilka som får dem

  • Formulär: vår databas hos Supabase, i EU (Stockholm).
  • Bokningar och mejl: Google Workspace / Google Kalender.
  • Webbplatsen: GitHub Pages, som tar emot din IP-adress när sidan laddas.
  • Mätning (med samtycke): Meta och Google.

Google, Meta och GitHub kan föra över uppgifter till USA. De omfattas av EU–US Data Privacy Framework. Vi säljer aldrig dina uppgifter.

Hur länge vi sparar dem

Uppgifter från formulär, bokningar och mejl sparar vi i högst 24 månader efter senaste kontakt om det inte blir ett samarbete. Blir det ett samarbete sparar vi det som behövs så länge avtalet gäller och det som bokföringslagen kräver. Mätdata från Meta och Google sparas enligt deras regler.

Dina rättigheter

Du har rätt att få veta vilka uppgifter vi har om dig, att få fel rättade, att få uppgifter raderade, att begränsa eller invända mot behandlingen, att få ut dina uppgifter och att när som helst återkalla ett samtycke. Mejla hello@luminatemedia.se så svarar vi inom en månad.

Tycker du att vi hanterar dina uppgifter fel kan du klaga hos Integritetsskyddsmyndigheten, imy.se.
